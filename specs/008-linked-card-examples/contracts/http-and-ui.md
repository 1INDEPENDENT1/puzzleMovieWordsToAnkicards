# Контракты HTTP и UI: связанные примеры

**Date**: 2026-11-10. Целевой контракт feature 008 после отказа от переноса старой коллекции. Все указанные новые поля и маршруты ещё предстоит реализовать. Существующие маршруты не переименовываются.

## Общие правила

- Идентичность владельца берётся исключительно из текущей session через SessionUserResolver. userId из запроса не принимается.
- 401 — нет пользовательской session; 404 — неизвестная/чужая карточка, пример, связь, snapshot; 400 — неверный формат/длина/страница; 409 — stale version, устаревший показ или конфликт состояния. Ошибки не изменяют данные.
- Ответы с переводами не кешируются между пользователями; Cache-Control: no-store. Все тексты выводятся через th:text/textContent, URL фильма допускает только http/https. Исходное HTML содержимое не исполняется.
- Ответы при успешных JSON-операциях 200. UUID карточки и optimistic version явны. После однократного построения коллекции используются идентификаторы только новых карточек.

## 1. Существующие страницы и импорт

| Маршрут | Поведение |
| --- | --- |
| GET /reviews | Показывает следующую доступную к повторению карточку и новый presentationId |
| GET /reviews/next | Существующая ReviewQueueResponse; новый presentationId при каждом новом показе |
| POST /reviews/cards?sourceExportId={uuid} | Проверки владельца/готовности/предупреждения, публикация сохранённого snapshot, redirect 302 /reviews как сейчас |
| GET /cards?page=0 | Одна строка на изучаемое слово; суммарная история, exampleCount и доступ к примерам |
| POST /reviews/cards/{id}/answer | Прежние answer и responseMillis; только доступная к повторению карточка, двоичная оценка сохраняется |
| PATCH /cards/{id} | Редактирование originalText и translationText слова с обязательной version; состояние повторения не меняется |

POST импорта при PARTIAL без ранее показанного предупреждения сохраняет 303 Location /exports/{jobId}; до этого публикации нет. Незавершённый export — 409. Snapshot отсутствует у старого completed job — 409 с требованием свежего экспорта. Наличие staged snapshot проверяется в БД, а не generatedData. После restart предупреждение снова может потребовать посещения export page по прежнему правилу session.

Повторная публикация одного snapshot возвращает redirect без дублей и сбросов. PHRASES-only сохраняет примеры и связывает с существующими словами; при пустом словаре создаёт ноль карточек и сообщает число сохранённых примеров. Ноль карточек здесь не ошибка. Не создаётся самостоятельная PHRASE карточка.

Answer инвалидирует presentation для отвеченной карточки; response.nextCard получает новый presentationId. Счётчики due учитывают обычные состояния scheduler. История и процент правильных ответов считаются по прямым ответам карточки, без умножения от JOIN на несколько примеров.

## 2. Проекция карточки

ReviewCardView сохраняет id, originalText, translationText, state, dueAt, lookupActions и version. Добавляются vocabularyEntryId, exampleCount, presentationId, effectiveContentVersion. Основная translationText содержит только перевод слова. instanceText и sourceContext больше не являются единственным источником контекста; в новой проекции могут быть null, примеры читаются отдельно.

Наличие main translation в редакторе или библиотеке не означает раскрытие примеров в режиме повторения. Отдельные endpoint выдачи переводов примеров применяют gate своего presentation. Библиотека — управление собственным материалом, а не защита секретов от владельца данных.

## 3. Показ примеров в режиме повторения

### GET /reviews/cards/{id}/examples?presentationId={uuid}&page=0

Проверить владельца и актуальный presentation для id и версии содержимого. Страница фиксированного размера 25, page >= 0; недопустимая страница для непустой коллекции — 400. Для пустой коллекции page=0 возвращает items=[], total=0. Никакого общего предела коллекции.

Ответ: cardId, presentationId, effectiveContentVersion, page, pageSize, total, items. Каждый item содержит exampleId, linkId, linkVersion, originalText, movieTitle, movieUrl и position (нумерация с 1 во всей коллекции). Translation text в этом ответе отсутствует, даже после main reveal. Порядок first_seen_order/id.

### POST /reviews/cards/{id}/reveal

Тело: presentationId. Проверяет владельца, id и текущую версию показа; отмечает mainRevealed=true только для этого показа. Ответ: cardId, presentationId, mainRevealed=true, translationText (только слова, может быть пустым). Повтор reveal одного показа идемпотентен; записей ReviewAttempt нет.

### POST /reviews/cards/{id}/examples/{exampleId}/translation

Тело: presentationId, linkVersion. Проверяет текущий показ и mainRevealed. Без main reveal — 409 `MAIN_ANSWER_NOT_REVEALED`. Пример должен быть связан именно с entry текущей карточки и тем же владельцем; наличие примера у владельца без этой связи недостаточно. Stale link version или content version — 409.

Ответ: cardId, presentationId, exampleId, linkVersion, translationText, translationAvailable. Используется effective link override либо source translation; отсутствие переводов даёт translationAvailable=false и пустой текст, не искусственный перевод. Запись истории, изменение due и статистики отсутствуют.

Нельзя обойти gate старой кнопкой «Translate sentence»: переводные lookup actions для контекста доступны только после main reveal; действие относится к текущему примеру. Обычные ссылки dictionary/pronunciation основного слова сохраняются.

## 4. Управление примерами и совместимость редактора

### GET /cards/{id}/examples?page=0

Только владелец карточки; тот же порядок/пагинация, но включает effective translationText и версии links для явного редактирования. Не требует review presentation.

### PATCH /cards/{id}/examples/{exampleId}

Тело: originalText, translationText, version (версия link). Исходный текст непустой, интерактивный предел 4000 символов; перевод до 8000, допускается намеренно пустой. Меняются только overrides этой WordExampleLink, не source VocabularyExample и не контексты других слов. Ответ: обновлённый item, cardId и effectiveContentVersion. Расписание/история не меняются. Одновременная чужая запись версии даёт 409, а не потерю правки.

### Редактор слова и конкретного примера

PATCH /cards/{id} принимает originalText, translationText и обязательную version. Пример редактируется отдельно по exampleId; instanceText не является поддерживаемым полем записи новой модели. Старые вкладки/запросы не обслуживаются compatibility-адаптером и не изменяют случайный первый пример.

Ручное изменение оригинала слова пересчитывает его связи внутри того же владельца, не меняет source identity и не сбрасывает scheduler. Overrides примеров сохраняются. Явный редактор может показывать пользователю его переводы до review reveal: это управление содержимым, а не действие «Перевод» учебного окна.

## 5. Первоначальное построение

Учебная коллекция создаётся с нуля по [fresh-start.md](../fresh-start.md). Старые карточки, ответы и правки не преобразуются; маршрутов отчёта перехода, выбора прежних значений или привязки старых карточек нет. Обычные последующие POST импорта не очищают новые данные и не обнуляют историю.

## 6. UI state machine

- Новый показ: MAIN_HIDDEN, окно закрыто, translations cache пуст. Кнопка «Примеры (N)» доступна и до main reveal; N=0 показывает явное отсутствие примеров.
- Открытие: original текущего примера, фильм или «Источник не указан», «i из N», назад/вперёд. На краях списка кнопки отключены; автоматического циклического перехода нет.
- MAIN_HIDDEN: действие «Перевод» disabled с пояснением сначала раскрыть основную карточку; mouse/keyboard обработчик тоже проверяет состояние.
- Reveal main: после успешного POST состояние MAIN_REVEALED; перевод слова показан, перевод примера по-прежнему скрыт.
- Reveal example: отдельное действие показывает только текущий перевод. При смене примера его перевод сбрасывается, включая возврат к ранее просмотренному.
- Закрытие и повторное открытие окна в том же показе сохраняют положение и main reveal, но скрывают перевод примера. Escape работает; focus возвращается к «Примеры». Открыть новый dialog поверх редактора нельзя.
- Answer/next/reload/изменение содержимого: прежний presentation инвалидируется, окно закрывается, обе стороны перевода сбрасываются. Поздние HTTP-ответы применяются только при совпадении presentationId, cardId, exampleId и версии; иначе игнорируются.
- Сетевой сбой не раскрывает перевод и не записывает answer; показываются ошибка и повтор действия. Истёкший presentation предлагает заново показать карточку.

## 7. Доступность и регрессия

Dialog имеет доступное имя, focus trap средствами dialog, кнопки с понятными именами, aria-live для положения/ошибок, закрытие Escape. CSS адаптирует текст и controls под мобильную ширину; reduced-motion отключает дополнительные переходы. Переводы не появляются от фокуса, перелистывания, ошибки или анимации. Существующие sweep и binary answer сохраняются.

Экспортные endpoints и формат двухколоночного TSV сохраняются. In-app examples используют полный match set; прежний display cap TSV может оставаться как отдельная проекция. Исправленные связи/дедупликация могут исправить содержимое строк; это не обещание побайтно идентичного ошибочного результата.
